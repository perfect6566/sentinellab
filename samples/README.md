# Grader samples

- `single-record.json`: one complete 25-feature record for `predict_single`.
- `batch-sample.csv`: five unlabeled development-partition records with stable `row_id` values.
- `labeled-sample.csv`: twenty development-partition records, ten from each true class, for tool-flow testing only.

These files are deterministic convenience samples derived only from the development partition. They are not hold-out results and must not be presented as estimates of production-model performance.
